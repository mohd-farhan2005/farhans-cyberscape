# Muhammad Farhan Portfolio

## Goal
Build a premium, responsive one-page portfolio that presents Muhammad Farhan as a full stack developer with a distinctive black-and-neon-green cyberpunk identity.

## What I’ll build
- Full-screen animated introduction with name, rotating developer roles, three clear actions, contact details, glowing particles, and smooth text reveals.
- About section with the supplied biography, concise animated career metrics, and restrained depth effects.
- Grouped skills with animated progress bars and staggered glass panels.
- Vertical work timeline for ecraftz and e-academy using the supplied responsibilities and dates.
- Glass-style education cards, glowing strengths, and animated language badges.
- Contact area with phone, email, LinkedIn, a functional success state, and a stylized interactive location panel.
- Minimal footer with social links, copyright, animated line, and back-to-top control.
- Loading sequence, neon cursor, scroll progress, smooth anchor navigation, section reveals, and responsive navigation.

## Visual direction
- Near-black layered background with neon green as the focused accent.
- Sharp editorial typography, restrained glass surfaces, luminous line work, and subtle animated gradients.
- Motion will feel smooth and intentional, with reduced-motion support and no excessive effects that distract from the content.

## Technical details
- Keep the project’s TanStack Start foundation and implement the requested experience in React, TypeScript, Tailwind CSS v4, and Motion.
- Define all color, typography, glow, and animation values as reusable semantic tokens.
- Add app-specific metadata and a single semantic page heading.
- Use local UI effects instead of external media to keep loading fast.
- Validate the finished page at desktop and mobile widths, including the contact interaction and navigation.
